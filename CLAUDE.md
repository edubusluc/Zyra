# Zyra · instrucciones para asistentes

- Empieza por `ZYRA_CONTEXT.md`: índice por funcionalidad, reglas críticas y comandos.
- Abre solo el documento de `docs/ai/` que enlace la fila del área afectada, y después solo los
  archivos de código y tests de esa fila. Amplía la búsqueda únicamente si una dependencia lo exige.
- El código manda sobre cualquier documento; si encuentras una discrepancia, corrige el documento en el mismo PR.
- Convenciones del repositorio: `docs/mantener-documentacion.md` (docstrings en español, novedades, accesibilidad).
- Si un cambio altera rutas, reglas, modelos o comandos, actualiza `ZYRA_CONTEXT.md` y el `docs/ai/*.md` afectado.
